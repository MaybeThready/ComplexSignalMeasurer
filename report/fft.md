# 快速傅里叶变换模块相关报告

## 1. 原理

单片机需要对采样得到的时域信号转换到频域进而进行更深层次的分析。一种可行的方法是使用 DFT 变换：

$$ X[k] = \sum_{n=0}^{N-1} x[n] e^{-{\frac{j2\pi kn}{N}}}, \quad k = 0, 1, \ldots, N-1 $$

这是傅里叶变换在有限长离散序列下的形式。DFT 的计算量为 O(N^2)，当 N 较大时，计算量会非常大，单片机的处理能力有限，因此需要使用快速傅里叶变换（FFT）算法来降低计算复杂度。

FFT 算法的主要思想是将 DFT 的计算分解为更小的 DFT 计算，从而减少计算量。常用的 FFT 算法有 Cooley-Tukey 算法，它将长度为 N 的 DFT 分解为两个长度为 N/2 的 DFT，递归进行，最终将计算复杂度降低到 O(N log N)。

## 2. 参数计算

题目要求得到的频域信号分辨率为 500Hz，至少涵盖 10kHz 到 500kHz 的频率范围。根据采样定理，采样频率应至少为信号最高频率的两倍，即 1000ksps。根据 DFT 的公式，得到离散序列与连续信号之间的关系：

$$ x[n] = f(nT_s), \quad n = 0, 1, \ldots, N-1 $$

$$ F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt = \int_{-\infty}^{\infty} f(nT_s)e^{-j\omega nT_s}d(nT_s) $$
